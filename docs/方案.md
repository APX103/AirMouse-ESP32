# AirMouse-Wireless 方案（v1）

> 接续有线版 AirMouse（D:\work\AirMouse）的无线化：
> **B 板 = 鼠标端**（接 IMU + 全部指针算法 + 无线发射）
> **A 板 = 接收端**（无线收包 → USB HID 鼠标 → 电脑）
> 效果：拔掉 B 板与电脑的一切连线，手持 B 板指哪打哪。

## 1. 无线链路选型

| 方案 | 单程延迟 | 连接管理 | 结论 |
|---|---|---|---|
| **ESP-NOW** ✅ | **1-4ms** | **免连接**（无配对/无路由，上电即发） | 选它。乐鑫私有 P2P 协议，两块 ESP32 天生支持 |
| WiFi UDP | 5-50ms，抖动大 | 需组网（AP/SoftAP+关联），掉线重连复杂 | 否 |
| BLE GATT | 7.5-15ms 起 | 配对+GATT 服务开发重 | 否 |
| BLE HID 直连（省掉 A 板） | 7.5-30ms | ESP32 BLE HID 栈在 Windows 上兼容性一般 | 列为 M6 实验路线 |
| 加 nRF24L01 硬件 | ~2ms | 需要额外硬件和 SPI 占用 | 否（有现成两板） |

## 2. 链路协议 airlink

数据包（12 或 16 字节，CRC8 校验）：

```
┌───────┬──────┬──────┬──────┬─────────┬───────┬───────┬───────┬───────┐
│ magic │ seq  │  dx  │  dy  │ buttons │ flags │ absX? │ absY? │ crc8  │
│ u16   │ u16  │ i16  │ i16  │ u8      │ u8    │ i16   │ i16   │ u8    │
└───────┴──────┴──────┴──────┴─────────┴───────┴───────┴───────┴───────┘
magic = 0xA179
buttons: bit0=左键 bit1=右键（每包全量重发，不怕丢包）
flags: bit0=含 abs 字段（包长16） bit1=warp（接收端把光标搬到 absX/absY）
crc8: poly=0x31 init=0xFF，覆盖除 crc 外全部字段
```

**关键机制：**

- **位移包**：光标有增量就发（跟随融合率，≤250Hz；静止冻结时自动静默）
- **心跳包**（500ms 一次）：携带鼠标端的绝对模型坐标 absX/absY →
  接收端比对自身累计位置，误差 >2px 时补发纠正位移 → **丢包导致的模型漂移被持续抹平**
- **warp 包**：BOOT 回中时发送，接收端分块搬运光标到屏幕中心（视觉瞬移）
- **配对**：鼠标端广播发送（FF:FF:FF:FF:FF:FF）；接收端锁定第一个合法源 MAC（magic+crc 通过），
  断链 10 秒后允许重新锁定。家庭环境足够，无需加密。
- **信道**：两端均未关联 WiFi，STA 默认驻留信道，天然一致；密集干扰环境后续可换信道。

## 3. 固件结构

```
firmware/
├── mouse/      （B板）复用有线版全部算法层，仅把 USB HID 换成 airlink 发送
│   ├── mouse.ino        主循环（按键→buttons位图，回中→warp包）
│   ├── airlink.h        协议定义（与 receiver 各持一份拷贝，Arduino 目录限制）
│   ├── link.h/.cpp      ESP-NOW 发送：队列/心跳/CRC/统计
│   ├── imu.* madgwick.h quat.h filters.h    ← 原样复用
│   ├── pointer.*        ← 原样复用（回调输出到 link）
│   ├── shell.*          ← stat 增加 link 统计
│   └── config.h statusled.h
└── receiver/   （A板）全新 ~300 行
    ├── receiver.ino     ESP-NOW 收包校验 → Mouse.move/press + 心跳同步 + 状态灯
    └── airlink.h
```

**设计原则：所有算法留在鼠标端**（融合、ray-cast、FOV、冻结、回中），
接收端只是「把位移翻译成 HID 报文」的哑桥——这样有线版验证过的逻辑一行不改。

## 4. 延迟预算（无线版）

| 环节 | 延迟 |
|---|---|
| 传感器采样+DLPF | 2-4ms |
| I2C@400kHz 读取 | 1.1ms（实测） |
| Madgwick 融合 | 0.02ms（实测外推） |
| **ESP-NOW 空口** | **1-4ms** |
| 接收端处理+USB HID | ≤1ms |
| **合计** | **≈5-11ms**（商用无线空鼠 20-60ms） |

## 5. 上电与联调流程

| 阶段 | 内容 | 通过判据 |
|---|---|---|
| M0 点火 | 双板烧录，先 A 后 B | A 板串口打印「已锁定鼠标端 MAC」；B 板 `stat` 显示 tx 正常 |
| M1 链路 | `stat` 观察 txOk/txFail/心跳 | 丢包率 <1%，心跳 abs 同步无跳变 |
| M2 透传 | `mode rate` 晃板子 | 光标动（验证全链路） |
| M3 成品 | `mode abs`，指中心按 BOOT | 无线指哪打哪 |
| M4 环测 | 距离（5-10m）、遮挡、同室 WiFi 干扰 | 无感知卡顿 |

## 6. 接线（烧录前照这个接）

**B 板（鼠标端）——与有线版完全一致，不用动！**

| 微雪 ICM20948 | B板 | | 可选按键 | B板 |
|---|---|---|---|---|
| VCC | 3V3 | | 左键 | GPIO47↔GND |
| GND | GND | | 右键 | GPIO21↔GND |
| SDA | GPIO41 | | 回中 | 板载BOOT键 |
| SCL | GPIO42 | | | |

供电：调试期 USB 线随便插（PC/充电宝均可）；日后换电池。

**A 板（接收端）——什么都不用接**，一根 USB 线插电脑的**原生 USB 口**（GPIO19/20）即可。

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 丢包 | 位移包丢失天然无害（下一帧纠正）；心跳 abs 同步兜底；按键全量重发 |
| 2.4GHz 干扰 | 换信道（一行配置）；ESP-NOW 重传 |
| 两端模型漂移 | 心跳 abs 校准（>2px 即纠正） |
| B 板功耗 | 静止时自动静默（只有 2Hz 心跳），后续加 deepsleep 唤醒 |
